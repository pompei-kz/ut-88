# План: всё на GitHub — по-русски

Задание: `01-prompt-russian-github.txt`.
Дополнения (ответы на вопросы): `03-prompt-russian-github-to-prompt.txt`.
Отклонения при исполнении — в `04-deviations-russian-github.md`.

## 1. Принятые решения

| Вопрос                 | Решение                                                                                                    |
|------------------------|------------------------------------------------------------------------------------------------------------|
| Английские документы   | удалить `docs/MANUAL.md` и `docs/ASSEMBLER.md`; `README.md` переписать по-русски                           |
| Служебные файлы GitHub | перевести CONTRIBUTING.md, CHANGELOG.md, NOTICE.md, шаблон issue, названия шагов CI, описание в Cargo.toml |
| Лицензии               | тексты `LICENSE-MIT` и `LICENSE-APACHE` остаются английскими — это стандартные юридические тексты          |
| Справка `-he`          | остаётся (английская справка ассемблера и компоновщика — по прежнему решению пользователя)                 |
| Комментарии в коде     | проверить и перевести английские остатки (по первичному поиску их почти нет)                               |

## 2. Этапы

1. **README.md по-русски.** Та же структура и содержание: описание, скриншоты, «Возможности»,
   «Требования» (cargo со ссылками https://rustup.rs и
   https://www.rust-lang.org/tools/install), «Быстрый старт — команды make» с описанием, что
   делать после каждой (`make base` — директивы, `make full` — «Тетрис» с управлением и др.,
   `make asm-run`/`asm-load`), ассемблер, горячие клавиши, документация, структура проекта,
   разработка, лицензия, благодарности. Ссылки — на `manual.md`, `doc/43-assembler.md`,
   `doc/README.md`. Названия микросхем — кириллицей. Подписи скриншотов — по-русски.
2. **Удалить** `docs/MANUAL.md` и `docs/ASSEMBLER.md`; во всех файлах заменить ссылки на них
   (`manual.md` — строка «English version», `doc/43-assembler.md`, `doc/README.md`, справка
   ассемблера, CHANGELOG и др.). Папка `docs/` остаётся только для `docs/img/` (скриншоты README).
3. **Служебные файлы GitHub:** CONTRIBUTING.md, CHANGELOG.md, NOTICE.md,
   `.github/ISSUE_TEMPLATE/bug_report.md`, названия задач и шагов в `.github/workflows/ci.yml`,
   `description`/`keywords` в `[workspace.package]` Cargo.toml (`keywords` crates.io требует
   латиницы — оставить латиницей, если иначе нельзя; записать в отклонения).
4. **Код:** найти английские комментарии, doc-комментарии и сообщения пользователю в `crates/`
   (кроме английской справки `-he`, тестовых данных и стандартных терминов) и перевести.
5. **Проверка:** все относительные ссылки в `.md` ведут на существующие файлы; поиск по
   репозиторию упоминаний `docs/MANUAL.md`, `docs/ASSEMBLER.md`, `README.md#…`-якорей;
   таблицы выровнены (`make align-md`); `cargo build`, `cargo test`, clippy, fmt — чисто (тесты,
   проверяющие тексты справки/документов, поправить при необходимости).

## 3. Исполнение

Агентами: (1) README.md + удаление английских документов и ссылок; параллельно (2) служебные
файлы GitHub + Cargo.toml + комментарии в коде. Коммиты — только с разрешения пользователя;
по типам: `doc` (README, NOTICE, CONTRIBUTING, CHANGELOG, шаблон issue, удаление docs/*.md),
`build` (CI, Cargo.toml), `refactor` или `doc` (комментарии в коде — уточнить тип при коммите).

## 4. Критерии готовности

- README.md и все служебные файлы GitHub — на русском; английских документов `docs/*.md` нет;
- нет битых ссылок; сборка и тесты чистые;
- английскими остаются только тексты лицензий и справка `-he`.
