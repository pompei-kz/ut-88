# Отклонения от плана и самостоятельные решения

План: `02-plan-asm-k580vm80a.md`.

| №   | Этап | Отклонение / решение                                                                                                                                                                                                                                                        | Причина                                                                        |
|-----|------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------|
| 1   | 9.1  | Исполнение агентами последовательно: ядро → препроцессор и листинг → объектные файлы и компоновщик → примеры и документация                                                                                                                                                 | агенты правят общие файлы (cli.rs, справка); параллельная правка рискованна    |
| 2   | 7    | `monitor/monitor.asm` собирается байт-в-байт в `monitor-fixed.bin`, а не в `monitor.bin`: отличаются 2 байта 006FH–0070H (`INX SP` вместо `DCX SP`)                                                                                                                         | в исходнике уже внесено исправление «ШАГ НАЗАД»; тест проверяет и это различие |
| 3   | 3    | Имена символов не зависят от регистра букв (как в Intel ASM-80/M80); зарезервированы регистры и слова-операторы                                                                                                                                                             | по monitor.asm не решить — там всё заглавными                                  |
| 4   | 3    | Метка — слово с двоеточием, слово с 1-го столбца (если не мнемоника) или имя перед EQU/SET/MACRO; метка на строке с ORG/CSEG/DSEG/ASEG получает адрес после директивы                                                                                                       | совместимость с распространёнными ассемблерами 8080                            |
| 5   | 3    | PUBLIC/GLOBAL, EXTRN/EXTERN и NAME разобраны уже на этапе ядра (до `Module.publics/externs/name`)                                                                                                                                                                           | нужны для проверки перемещений внешних символов                                |
| 6   | 2    | Дополнительные ключи `--fill XX`, `--charset koi7|ascii`, `--base АДРЕС` (база CSEG; по умолчанию 0000, DSEG — сразу за CSEG)                                                                                                                                               | `--fill` и `--charset` есть в плане как опции, `--base` — из п. 3.8            |
| 7   | 3    | Выражения в i64; байт −256…255, слово −65535…65535; сравнения дают 0FFFFH/0; HIGH/LOW связывают сильнее бинарных операций (как в Intel); `'AB'` = 4142H; `$` — адрес начала строки                                                                                          | правила Intel ASM-80                                                           |
| 8   | 3    | КОИ-7: строчные русские = заглавные, Ё = Е, «Ъ» — ошибка (нет в знакогенераторе); строчные латинские остаются 61H–7AH; кодировка действует и на символьные константы                                                                                                        | так устроен знакогенератор ЮТ-88                                               |
| 9   | 3    | При ошибках 1-го прохода 2-й не запускается, выводятся все ошибки прохода сразу                                                                                                                                                                                             | меньше наведённых ошибок                                                       |
| 10  | 4    | Дамп hex: каждый непрерывный кусок памяти отдельно, первая строка — с фактического адреса, далее на границе 16, пропуски не заполняются; Intel HEX — записи по границам 16, затем 03 (пуск), затем 01                                                                       | эмулятор такой дамп читает; адрес начала не теряется                           |
| 11  | 4    | DS без заполнителя только резервирует: внутри bin пропуск заполняется `--fill`, резерв в конце в файл не попадает                                                                                                                                                           | не раздувать образ                                                             |
| 12  | 2    | Коды выхода: 0 — успех, 1 — ошибки сборки, 2 — ошибка командной строки; без аргументов — подсказка и 0; ошибки clap переведены на русский; `--help` = `-h`                                                                                                                  | —                                                                              |
| 13  | 3    | Препроцессор передаёт ассемблеру и свои строки (`LineKind`: директивы, ложные ветки, ошибки) — для листинга и вывода всех ошибок сразу; метка на IF/INCLUDE/REPT/вызове макроса определяется, на ELSE/ENDIF/ENDM — ошибка                                                   | листинг должен показывать все строки                                           |
| 14  | 3    | IF/IFDEF смотрят только на символы, определённые выше по тексту или ключом `-D`; ссылка вперёд в IF и REPT — ошибка; IF, открытый во включённом файле или макросе, должен закрыться там же                                                                                  | значение условия должно быть известно на обоих проходах одинаково              |
| 15  | 3    | Параметры макроса подставляются по словам без учёта регистра; в кавычках — только `&ИМЯ`; аргумент в `<…>` — без скобок; недостающие аргументы пустые, лишние — ошибка; LOCAL → `??0001`…; переопределение макроса разрешено (как в M80)                                    | совместимость с M80                                                            |
| 16  | 3    | Ограничения: вложенность макросов и REPT — 64, INCLUDE — 16, повторов REPT — 0…65535; рекурсия INCLUDE — по полному пути                                                                                                                                                    | защита от зацикливания                                                         |
| 17  | 4    | Листинг — как monitor.lst: 4 байта в строке с переносом; `'` — смещение в CSEG, `"` — в DSEG; `+` — раскрытие, `-` — ложная ветка; адреса CSEG/DSEG — смещения без учёта `--base`; при ошибках листинг не создаётся                                                         | совпадение с monitor.lst байт-в-байт                                           |
| 18  | 5    | База CSEG по умолчанию: у компоновщика C000H (начало ОЗУ ЮТ-88), у ассемблера — 0000; `--base` компоновщика — синоним `--cseg`                                                                                                                                              | так в плане; для одинакового результата базу задают обоим                      |
| 19  | 5    | Формат .link уточнён: строка `END` (обнаружение обрезанного файла), комментарии `;` целыми строками, `ASEG n` для абсолютных значений, `PUBLIC … EXT имя ±n`, необязательное `AT файл:строка:столбец`, DATA до 16 байт; полная таблица символов не хранится — только PUBLIC | читаемость, точные места ошибок                                                |
| 20  | 5    | LOW/HIGH: адрес цели плюс константа должен быть в 0000H–FFFFH, иначе ошибка; WORD — по модулю 10000H; проверка в общем `Module::place`                                                                                                                                      | однозначность байта адреса                                                     |
| 21  | 5    | Перекрытие проверяется по сегментам CSEG/DSEG целиком (включая резервы DS), по ASEG — по блокам данных                                                                                                                                                                      | резерв DS тоже занимает память                                                 |
| 22  | 5    | Каждый объявленный EXTERN должен разрешиться, даже если не используется; имена PUBLIC/EXTERN без учёта регистра                                                                                                                                                             | как в ассемблере                                                               |
| 23  | 5    | Ассемблер: `--base` вместе с `-t link` — ошибка командной строки, `--fill` для .link игнорируется; компоновщик не пишет .link                                                                                                                                               | размещением занимается компоновщик; слияние в один .link не поддерживается     |
| 24  | 5    | Константа, импортированная через EXTRN, считается перемещаемой: выражение из двух внешних символов (`BUF+BUFLEN`) записать нельзя                                                                                                                                           | общее правило перемещаемости ассемблера                                        |
