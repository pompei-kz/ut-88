# Отклонения от плана и самостоятельные решения

План: `02-plan-create-emulator.md`.

| №   | Этап | Отклонение / решение                                                                                                                                                    | Причина                                                                  |
|-----|------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------|
| 1   | 1–3  | Этап 1 (разбор журналов) и этапы 2–3 (каркас, процессор) выполняются параллельно агентами                                                                               | по указанию пользователя «используй агенты»; процессору журналы не нужны |
| 2   | 1    | Новые файлы `doc/` нумеруются диапазонами: 11–19 разное, 20–29 дисплейный модуль, 30–39 ОС и CP/M, 40–49 программы                                                      | агенты пишут параллельно и не должны пересекаться по именам              |
| 3   | 3    | Тестовые программы 8080 лежат в `crates/i8080/tests/roms/`, а не в корневом `tests/roms/`                                                                               | тесты относятся к крейту процессора                                      |
| 4   | 3    | Тестовые программы скачаны из github.com/superzazu/8080 (коммит c5d403c); 8080PRE/8080EXM — GPL v2+, CPUTEST — без явной лицензии; источник и SHA-256 в README.md рядом | нужны для проверки процессора; лицензии зафиксированы                    |
| 5   | 3    | `interrupt(&mut bus, opcode) -> Option<u32>`: прерывание исполняется сразу; `None` — не принято (INTE=0 или задержка после EI), машина держит запрос                    | удобнее для машины ЮТ-88                                                 |
| 6   | 3    | По INTA поддерживаются только однобайтные коды (RST); цикл прерывания — 11 тактов                                                                                       | в ЮТ-88 по INTA приходит только RST 7                                    |
| 7   | 3    | В состоянии HLT `step` возвращает 4 такта                                                                                                                               | чтобы время (часы, магнитофон) шло во время останова                     |
| 8   | 3    | `reset()` меняет только PC, INTE, задержку EI и HLT, остальные регистры сохраняются; счётчик тактов не обнуляется                                                       | так ведёт себя настоящий 8080                                            |
| 9   | 3    | Дизассемблер помечает недокументированные коды звёздочкой (`*NOP`, `*JMP`); числа — с ведущим 0 перед буквой (`0C000H`)                                                 | соглашение ассемблера Intel                                              |
| 10  | 3    | 8080EXM помечен `#[ignore]` и запускается `cargo test --release -- --ignored` (~15 с, в debug — минуты)                                                                 | быстрый обычный `cargo test`                                             |
| 11  | 2    | `clap` подключён версией «4»; поле `license` в Cargo.toml не задано                                                                                                     | лицензию проекта не обсуждали                                            |
| 12  | 13   | Файлы программ (`programs/`) сделаны на этапе 1, а не 13                                                                                                                | агент искал программы в журналах при их разборе                          |
| 13  | 13   | В журналах нет программ «Болотуду» и «Жизнь» — только правила; вместо `.bin` сделаны описания `doc/40-bolotudu.md`, `doc/41-zhizn.md`                                   | в журналах их нет                                                        |
| 14  | 13   | Добавлены программы `display-test` (тест дисплейного модуля, 1989-09) и `programmator` (программатор ПЗУ, 1990-05)                                                      | найдены при поиске листингов                                             |
| 15  | 13   | Контрольная сумма программатора 62B9H из журнала совпадает с алгоритмом директивы K МОНИТОРА-F, а не с простой суммой директивы 8 (A9B9H); в README даны обе            | в журнале противоречие                                                   |
| 16  | 13   | «Гамма» обрезана по C082H, как в тексте; «Реакция» оставлена до C05FH (весь дамп), хотя в тексте «по C050H»                                                             | текст журнала противоречит дампу                                         |
| 17  | 13   | Управление в «Тетрисе» восстановлено по коду и экранным строкам программы                                                                                               | в журнале правил нет                                                     |
