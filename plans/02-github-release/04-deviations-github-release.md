# Отклонения от плана и самостоятельные решения

План: `02-plan-github-release.md`.

| №   | Этап | Отклонение / решение                                                                                                                                 | Причина                                                                                                   |
|-----|------|------------------------------------------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------|
| 1   | 2    | README начинается с описания, скриншотов и требований (cargo + ссылка), затем — команды make                                                         | задание: «вначале сказать, что должна быть установлена cargo»                                             |
| 2   | 4    | `rust-version = "1.89"`, а не 1.85 из плана; в manual.md и docs/MANUAL.md тоже 1.89                                                                  | let-chains в коде (Rust 1.88) и зависимость uuid 1.29 (Rust 1.89); на тулчейне 1.89 сборка не проверялась |
| 3   | 4    | Описания отдельных крейтов в их Cargo.toml оставлены русскими; английское `description` — только в `[workspace.package]`                             | крейты не публикуются на crates.io                                                                        |
| 4   | 4    | В NOTICE.md добавлен раздел о CP/M 2.2 (Digital Research) и о встраивании ПЗУ в бинарник через `include_bytes!`                                      | эти материалы тоже не покрываются лицензией кода                                                          |
| 5   | 4    | CI: основная задача — fmt, build, test, clippy; долгие `#[ignore]`-тесты — отдельная задача раз в неделю и вручную, без ut88-audio                   | долгие тесты идут минуты; тест ut88-audio требует звуковой карты                                          |
| 6   | 2    | Адрес репозитория в бейдже и `git clone` — `github.com/pompei-kz/ut-88`                                                                              | взят из `git remote`                                                                                      |
| 7   | 2    | Пакеты X11/Wayland в apt-команде README — только runtime; -dev ставятся лишь в CI                                                                    | библиотеки окна загружаются через dlopen                                                                  |
| 8   | 3    | В английском руководстве русские надписи интерфейса и экранные сообщения даны в оригинале с переводом; плейсхолдеры ключей переведены (FILE, ADDR …) | интерфейс эмулятора на русском                                                                            |
| 9   | 2    | Квазидиск в английских текстах — «RAM disk (the "quasi-disk", «квазидиск»)»                                                                          | единый термин в README и docs/MANUAL.md                                                                   |
| 10  | 2    | Скриншоты «Тетриса» и CP/M обрезаны до экрана телевизора, base и full — окно целиком                                                                 | чтобы текст на экране читался                                                                             |
| 11  | 4    | Лицензии и NOTICE закоммичены как `doc`, Cargo.toml, CI, .editorconfig, шаблон issue и .gitignore — как `build`                                      | подходящие имеющиеся типы                                                                                 |
