# 10. Система команд микропроцессора КР580ВМ80А

Таблица с вкладки журнала. Шестнадцатеричные коды и мнемоника — как у Intel 8080.

## Обозначения

| Обозначение         | Смысл                                                              |
|---------------------|--------------------------------------------------------------------|
| `[ ]`               | регистр или регистровая пара                                       |
| `[[ ]]`             | ячейка памяти по адресу из регистровой пары                        |
| `←`                 | направление передачи данных                                        |
| `DATA[8]`, `dd`     | байт данных (второй байт команды)                                  |
| `DATA[16]`          | два байта данных (второй и третий байты команды, младший первым)   |
| `ADDR[16]`, `ll hh` | 16-разрядный адрес ячейки памяти (младший байт `ll`, старший `hh`) |
| `pp`                | адрес порта (второй байт команды)                                  |
| `PCL`, `PCH`        | младший и старший байты счётчика команд PC                         |
| `ВУ`                | внешнее устройство (порт)                                          |
| `FLAG`              | регистр признаков                                                  |
| `M`                 | ячейка памяти по адресу в HL                                       |

Столбец признаков `S Z AC P C`: `*` — команда влияет на признак, `-` — не влияет,
`0`/`1` — признак принудительно сбрасывается/устанавливается.

Такты — число тактов процессора (при 2 МГц такт равен 0,5 мкс). Две цифры через дробь
(например, 11/17) означают: условие не выполнено / выполнено.

*Прим.: таблица заново сверена с документацией Intel 8080. Явные опечатки журнала
исправлены: например, у `INR B` в журнале написано «[A] ← [B]+1». Для `POP` журнал
указывает 11 тактов, для `HLT` — 4; здесь даны значения из документации (10 и 7). У
`SUB A` и `XRA A` в журнале показаны фактические значения признаков, а здесь — общее
правило группы.*
