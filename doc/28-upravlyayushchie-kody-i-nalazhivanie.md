# 28. Дисплейный модуль: управляющие коды, конструкция, налаживание

*Источник: «ЮТ для умелых рук», 1989, № 9, с. 12 (рубрика «Твой персональный компьютер»,
«От индикаторов — к экрану. Дисплейный модуль „ЮТ-88“», окончание).*

## Управляющие коды

Управляющие коды, как ясно из названия, ответственны за управление отображением информации на
экране дисплея. Вот их перечень.

**Функции управления курсором**

| Код | Обозначение (эквивалентная операция) | Функция                                                    |
|-----|--------------------------------------|------------------------------------------------------------|
| 08  | ← (УС+H)                             | перемещение курсора на одну позицию влево                  |
| 0A  | ПС (УС+F)                            | перевод строки                                             |
| 0C  | (УС+L)                               | установка курсора в нулевую позицию — в верхний левый угол |
| 0D  | ВК (УС+M)                            | установка курсора в начало строки                          |
| 18  | → (УС+X)                             | перемещение курсора вправо на одну позицию                 |
| 19  | ↑ (УС+Y)                             | перемещение курсора на одну позицию вверх                  |
| 1A  | ↓ (УС+Z)                             | перемещение курсора на одну позицию вниз                   |
| 1B  | АР2 (УС+:)                           | прямая адресация курсора                                   |
| 1F  | СТР (УС+‘)                           | чистка экрана                                              |

*Прим.:*

- *«ПС (УС+F)» — по-видимому, опечатка: УС даёт код клавиши AND 1FH, и 0AH получается из J
  (4AH), а F (46H) даёт 06H. Аналогично 1BH получается из «[» (5BH), а не из «:»; 1FH — из «_»
  (5FH).*
- *По коду МОНИТОРА-«F» символ 0DH отдельно не обрабатывается (он заносится в экранное ОЗУ как
  пустой символ), а 0AH переводит курсор в начало следующей строки — см.
  [27-monitor-f.md](27-monitor-f.md).*

Функция перемещения курсора в них и перевода строки действуют одинаково до тех пор, пока курсор
не окажется в нижней строке экрана. В этом случае при выполнении функции перевода строки
нижняя строка становится второй снизу, вторая — третьей и т. д., а верхние строки будут
теряться. При выполнении кода перемещения курсора на одну позицию вниз (если он находился на
нижней строке) он перемещается в ту же позицию на верхней строке экрана.

**Прямая адресация курсора (АР2)** позволяет устанавливать курсор в любую позицию на экране.
Для этого необходимо набрать последовательность кодов **1B (АР2) 59 (Y) AX, AY**, где AX —
позиция строки относительно левого верхнего угла, AY — позиция знакоместа в строке. Напомним,
что размер экрана в «ЮТ-88» — **28 строк на 64 знакоместа**. Все перечисленные в таблице коды
можно реализовать, нажав либо отдельную клавишу, либо одновременно две: УС+…

*Прим.: по коду МОНИТОРА к номерам строки и столбца прибавляется 20H (как в «РК-86»):
`1B 59 20+строка 20+столбец`.*

Алфавитно-цифровые коды «ЮТ-88» (таблица на той же странице) приведены в
[26-znakogenerator.md](26-znakogenerator.md).

## Конструкция

Дисплейный модуль размещается на отдельной плате из фольгированного стеклотекстолита. Общий
провод и цепь питания выполнены печатными проводниками, остальной монтаж — тонким
изолированным проводом. Дисплейный модуль соединяется по шине данных, шине адреса и сигналам
управления с помощью разъёма. Возможны и другие варианты конструкции, например, когда
дисплейный модуль крепится непосредственно сверху процессорного модуля с помощью четырёх стоек
из изоляционного материала.

## Налаживание

Налаживание модуля начинайте с проверки монтажа. Прозвоните все соединения по шинам питания и
выводам микросхем и убедитесь, что нет коротких замыканий. Затем подключите питание к плате.
На этом этапе налаживания с процессорного модуля на дисплейный модуль «скруткой» или витым
парным проводом передаются **только импульсы синхронизации частотой 16 МГц**. Проверьте с
помощью осциллографа наличие строчных и кадровых синхроимпульсов. Затем — наличие импульсов на
выходе счётчиков знакомест по горизонтали и вертикали. Наконец, подключите видеовыход
дисплейного модуля к телевизору и добейтесь, чтобы весь экран был заполнен случайным набором
символов. Только после этого через разъём соедините дисплейный модуль с процессорным.

Но переходить к проверке дисплейного модуля в динамике можно, лишь убедившись, что нет
нарушений в работе процессорного модуля. К примеру, если не проходит тест индикации — директива
«3», то проверку дисплейного модуля необходимо провести в статике. После тщательного контроля
разводки шины данных и шины адреса отключите дисплейный модуль от разъёма процессорного модуля
и запишите директивой «1» в ОЗУ программу отладки.

**Программа отладки дисплейного модуля в статике**

| Адрес | Код | Комментарий                                                                                                                      |
|-------|-----|----------------------------------------------------------------------------------------------------------------------------------|
| C000H | 3E  | код засылается в регистр A микропроцессора, значение его задаётся также AA                                                       |
| C001H | 55  |                                                                                                                                  |
| C002H | 32  | пересылка кода 55 или AA в ячейку памяти ОЗУ с адресом F400H; значение адреса также задаётся равным E800H                        |
| C003H | 00  |                                                                                                                                  |
| C004H | F4  |                                                                                                                                  |
|       |     | *шаг исполнения — дисплейный модуль подключают к процессорному*                                                                  |
| C005H | 3A  | чтение ОЗУ с адресом F400H и пересылка кода из этой ячейки в регистр A микропроцессора; адрес ячейки также задаётся равным E800H |
| C006H | 00  |                                                                                                                                  |
| C007H | F4  |                                                                                                                                  |
|       |     | *шаг исполнения*                                                                                                                 |
| C008H | C3  | зацикливание программы записи/чтения ОЗУ                                                                                         |
| C009H | 00  |                                                                                                                                  |
| C00AH | C0  |                                                                                                                                  |

*Прим.: в мнемонике — `MVI A,55H; STA 0F400H; LDA 0F400H; JMP 0C000H`. Программа проверяет
ОЗУ МОНИТОРА (F400H) и экранное ОЗУ (E800H) кодами 55H и AAH; шаги выполняются директивами
МОНИТОРА-«0».*
