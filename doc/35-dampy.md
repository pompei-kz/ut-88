# 35. Распечатки кодов выпуска 1990-02: ОС ЮТ-88, CP/M-64, CH.COM, CP/M-35

*Источник: «ЮТ для умелых рук» 1990-02, с. 2–6 и 9–16 (таблицы шестнадцатеричных кодов).
Всё, что ниже сказано о содержимом кода (разбор, назначение подпрограмм), — не из журнала, а
результат дизассемблирования переписанных распечаток.*

## Как переписано

Каждая строка распознана по изображению шаблонным сравнением глифов (шаблоны собраны по
напечатанным адресам строк), затем все сомнительные цифры, все расхождения двух независимых
прогонов распознавания и все спорные пары E/F, B/D/8 просмотрены глазами по изображению. После
этого — сверка с контрольными суммами журнала; блоки с расхождением просмотрены построчно
повторно. Для CP/M дополнительно использована перекрёстная проверка: CCP и БДОС в CP/M-64 и
CP/M-35 — один и тот же код CP/M 2.2, отличающийся только старшими байтами адресов (на 90H),
поэтому любое другое расхождение указывает на ошибку в одной из распечаток.

Контрольная сумма — 16-битная сумма всех байтов блока (директива «K» МОНИТОРА-«F»).

Четыре несошедшихся блока просмотрены по изображению построчно (каждый байт рядом с
результатом распознавания); других расхождений с напечатанным не найдено. Вероятно, в этих
блоках опечатки самой распечатки (или таблицы сумм). Найденная подозрительная команда:

- **3320H**: напечатано `4D` — команда в F86FH (после переноса в F800H) читается как
  `JNZ FA4DH`, то есть переход в середину команды `JMP FA39H` по адресу FA4CH. По смыслу
  (цикл прокрутки экрана FA68H–FA6FH) должно быть `JNZ FA68H`, то есть байт `68`; тогда
  сумма блока 3000H стала бы на 27 больше — расхождение сократилось бы до 3. В файле оставлено
  как напечатано (`4D`).

*Прим.: в 48C6H CP/M-35 на скане читается скорее `F9` (`JMP 41F9H`), а в том же месте
CP/M-64 — `E9` (`JMP D1E9H`, начало подпрограммы). В файл записано `E9`: так требует и
совпадение кода с CP/M-64, и контрольная сумма (с `F9` расхождение было бы 22). Оставшееся
расхождение 6 — в БСВВ CP/M-35 (4A00H–4BFFH), которую не с чем сравнить.*

### CH.COM

Контрольных сумм нет. Распечатка просмотрена построчно; тексты сообщений в коде читаются
без ошибок.

## Разбор: ОС ЮТ-88

Стартер (3000H–303FH):

```
3000  LXI H,3050H / CALL F818H   ; сообщение «СТАРТЕР "ОС ЮТ*88" ВЫКЛЮЧИТЕ ПЗУ МОНИТОРА…»
3006  LXI SP,3003H
3009  MVI A,8BH / OUT 04H        ; ППА клавиатуры
300D  XRA A / OUT 07H / IN 06H   ; ждать нажатия любой клавиши
3019  LXI H,30B0H / LXI D,F800H / PUSH D
3020  копирование до D=00H       ; 30B0H–38AFH → F800H–FFFFH
3029  MVI A,C3H / STAX D         ; в 0000H — код JMP
302C  LXI D,C000H, копирование до D=E0H   ; 38B0H–58AFH → C000H–DFFFH
303F  RET                        ; на F800H
```

Текст сообщений — КОИ-7 (строчные латинские буквы = русские): «СТАРТЕР "ОС ЮТ*88"»,
«ВЫКЛЮЧИТЕ ПЗУ МОНИТОРА И НАЖМИТЕ ЛЮБУЮ КЛАВИШУ», «**** ОС * ЮТ-88 ****», приглашение
«ЮТ*88>». В области ассемблера — сообщения «ERRORS DETECTED:», «ASSM.*МИКРОН*», «EDIT
*МИКРОН*», «PLEASE 1,2,3,CTRL"C"», «TOO LONG»; таблица мнемоник КР580ВМ80А (по 6 байт:
4 символа, код, тип) — с 3E7DH распечатки (C5CDH после переноса).

## Разбор: CP/M-64

### Загрузчик (3100H–313FH)

```
3100  LXI H,3400H / LXI D,C400H
3106  копирование до HL=4C00H        ; 3400H–4BFFH → C400H–DBFFH (CCP, БДОС, БСВВ)
3116  LXI SP,1C00H / LXI H,4FFFH
311C  MVI A,FEH / OUT 40H            ; открыть блок 1 квазидиска
3120  MOV D,M / DCX H / MOV E,M / DCX H / PUSH D   ; до HL=33FFH
                                     ; 3400H–4FFFH → квазидиск 0000H–1BFFH
312B  MVI A,FFH / OUT 40H            ; закрыть квазидиск
312F  LXI H,31E0H / LXI D,F500H, копирование до H=33H   ; 31E0H–32FFH → F500H–F61FH
313F  JMP DA00H                      ; BOOT
```

### БСВВ (4A00H–4BFFH в распечатке, DA00H–DBFFH после загрузки)

| Адрес | Назначение                                                                                                          |
|-------|---------------------------------------------------------------------------------------------------------------------|
| DA00  | вектор из 17 переходов (см. [31-cpm.md](31-cpm.md))                                                                 |
| DA33  | DPH диска A                                                                                                         |
| DA43  | таблица трансляции секторов 1…8                                                                                     |
| DA4B  | DPB: SPT=8, BSH=3, BLM=7, EXM=0, DSM=39H, DRM=1FH, AL0=80H, AL1=0, CKS=8, OFF=6                                     |
| DA5A  | заставка: 1FH (очистка экрана), 0AH, « CPM V - 2.2  DISK RAM - 256K.», 0AH, 0                                       |
| DA80  | BOOT: SP=0100H, вывод заставки, 0003H=0, 0004H=0, переход на GOCPM                                                  |
| DA93  | вывод строки до 0 через F809H                                                                                       |
| DA9E  | WBOOT: SP=0080H, SELDSK 0, HOME, чтение 2CH секторов с дорожки 0, сектора 1 в C400H                                 |
| DAE7  | GOCPM: `DI`, 0000H: `JMP DA03H`, 0005H: `JMP CC06H`, DMA=0080H, C=(0004H), `JMP C400H`                              |
| DB09  | LISTST: A=FFH                                                                                                       |
| DB0C  | HOME: SETTRK 0                                                                                                      |
| DB11  | SELDSK: C=0 → HL=DA33H, иначе HL=0                                                                                  |
| DB2A  | SETTRK: дорожка 0–63 → порт FEH, 64–127 → FDH, 128–191 → FBH, 192–255 → F7H; остаток в DBEDH                        |
| DB5E  | SETSEC: сектор в DBEEH                                                                                              |
| DB63  | SECTRAN: HL = таблица[C]                                                                                            |
| DB6D  | SETDMA: в DBEFH                                                                                                     |
| DB73  | READ: SP ← адрес сектора, `OUT 40H`, 64 раза `POP D` / `MOV M,E` / `MOV M,D`, `OUT 40H` ← FFH, SP восстановлен, A=0 |
| DB9E  | WRITE: SP ← адрес сектора + 80H, HL ← DMA+7FH, 64 раза `MOV D,M` / `MOV E,M` / `PUSH D`, закрыть, A=0               |
| DBC8  | адрес сектора в блоке = дорожка × 400H + (сектор − 1) × 80H                                                         |
| DBEC  | рабочие ячейки: порт (DBEC), дорожка (DBED), сектор (DBEE), DMA (DBEF), адрес (DBF2), SP (DBF4)                     |

### Драйвер CONOUT (31E0H–32FFH, работает в F500H–F61FH)

Обрабатывает ESC-последовательности и выводит символы через F809H: ESC A — 19H (курсор
вверх), ESC B — 1AH (вниз), ESC C — 18H (вправо), ESC D — 08H (влево), ESC E — 1FH (очистка
экрана), ESC H — 0CH (курсор в начало), ESC J — стереть до конца экрана, ESC K — до конца
строки, ESC Y строка столбец — позиционирование курсора. Пользуется ячейкой адреса курсора
МОНИТОРА-«F» F75AH. Управляющие коды, кроме 08H, 0AH, 0DH, 1BH, отбрасываются.

## Разбор: CH.COM и CP/M-35

CH.COM (0100H–03FFH): `JMP 01EBH`, далее тексты «CHANGER VERS 1.1», «READY TR FOR INPUT,
PRESS CR.», «READY TR FOR OUTPUT, PRESS CR.», «READY TR FOR VERIFY, PRESS CR.», «READ
ERROR.», «VERIFY ERROR.», «NO SOURCE FILE PRESENT.», «NOT ENOUGH MEMORY.», «NO DIRECTORY
SPACE.», «DISK FULL.»; работа с магнитофоном — через F806H/F80CH, с диском — через BDOS
(`CALL 0005H`).

CP/M-35: CCP с 3400H, БДОС с 3C00H (вход 3C06H), БСВВ с 4A00H (заставка «35K CP/M VERS
2.2»). CCP и БДОС совпадают с CP/M-64 (кроме старших байтов адресов, данных в буферах и
рабочих ячейках). БСВВ — другая, на основе БСВВ для 8-дюймового диска (26 секторов на дорожке,
таблица трансляции 1…26), с непонятными обращениями к портам F3H, FCH, FDH и ссылками на
адреса 74xxH и 4D72H вне распечатки; как именно в ней устроен «квазидиск в основном ОЗУ», по
распечатке до конца не разобрано.
