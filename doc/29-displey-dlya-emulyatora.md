# 29. Дисплейный модуль — сводка для эмулятора

*Это не перевод журнала, а сводка фактов из статей № 4–9 за 1989 г.
([20](20-displeynyy-modul.md)–[28](28-upravlyayushchie-kody-i-nalazhivanie.md)), схемы и
разбора МОНИТОРА-«F» ([27](27-monitor-f.md)). Что взято из текста журнала, что прочитано по
схеме и что выведено из кода — помечено.*

## Карта памяти (с дисплейным модулем)

| Адреса      | Что                                                                | Откуда                      |
|-------------|--------------------------------------------------------------------|-----------------------------|
| 0000H–03FFH | ПЗУ МОНИТОРА-«0» процессорного модуля                              | № 2                         |
| 9000H–9FFFH | светодиодные индикаторы процессорного модуля (9000H–9002H)         | № 2; пишет обработчик часов |
| C000H–C3FFH | ОЗУ процессорного модуля (C3FDH–C3FFH — часы МОНИТОРА-«0»)         | № 2                         |
| E000H–EFFFH | экранное ОЗУ 2 Кбайт (DD5–DD8); МОНИТОР-«F» использует E800H–EEFFH | текст № 4; код МОНИТОРА     |
| F400H–F7FFH | ОЗУ МОНИТОРА-«F» 1 Кбайт (DD25, DD26): стек, рабочие ячейки, часы  | текст № 5                   |
| F800H–FFFFH | ПЗУ МОНИТОРА-«F» 2 Кбайт (DD27), `roms/monitor-f.bin`              | текст № 5, дамп № 8         |

- Экранное ОЗУ — 2 Кбайта в окне 4 Кбайта. Вероятнее всего, A11 не декодируется и
  E000H–E7FFH дублирует E800H–EFFFH (вывод по схеме; МОНИТОР-«F» обращается только к
  E800H–EFFFH). Для эмулятора: одно ОЗУ 2 Кбайта, адрес = A & 07FFH.
- Сигналы выборки со шины управления процессорного модуля: EXXX (E000H–EFFFH), FXXX
  (F000H–FFFFH). Область F000H–F3FFH дисплейный модуль не занимает (МОНИТОР-«F» по директиве U
  передаёт туда управление — вероятно, для расширений).
- Запуск: сброс процессорного модуля ведёт на 0000H (МОНИТОР-«0»). МОНИТОР-«F» запускают
  переходом на F800H (холодный старт) или F86CH (тёплый). В режиме «часы в МОНИТОРЕ-«F»» ОЗУ
  переключают на 0000H и кладут туда `DI; JMP F800H`, а в 0038H — `JMP FFC1H` (№ 8).

## Порты ввода/вывода

| Порт    | Направление | Назначение                                                                                                         | Откуда               |
|---------|-------------|--------------------------------------------------------------------------------------------------------------------|----------------------|
| 04H     | вывод       | регистр управляющего слова ППА клавиатуры DD19 (пишется 8BH)                                                       | код МОНИТОРА (F836H) |
| 07H     | вывод       | канал А ППА: столбцы клавиатуры (0 в разряде — опрашиваемый столбец)                                               | код (FDB8H)          |
| 06H     | ввод        | канал В ППА: строки клавиатуры, биты 0–6 (0 — нажата); бит 7 должен быть 0                                         | код (FDBCH, FDCDH)   |
| 05H     | ввод        | канал С ППА: бит 0 — РУС, бит 1 — УС, бит 2 — СС (0 — нажата)                                                      | код (FE0CH), схема   |
| A1H     | ввод/вывод  | бит 0 — магнитофон (вход и выход), он же звук нажатия клавиш                                                       | № 2, № 8, код        |
| F8H–FBH | —           | ППА «дополнительного интерфейса» ПЗУ: FBH ← 82H, FAH ← ст. байт адреса, F9H ← мл. байт, F8H → данные (директива R) | код (F83AH, FA62H)   |

*Прим.: адреса портов клавиатуры получаются «вывернутыми»: управляющее слово (A1A0 = 11 у
ВВ55) пишется в порт 04H, канал А — 07H, В — 06H, С — 05H. То есть разряды адреса A0, A1 на
входы ППА, по-видимому, подаются с инверсией, а сам ППА выбирается в области 04H–07H. Для
эмулятора: регистр ППА = 3 − (порт & 3), порты 04H–07H.*

## Видео

| Параметр               | Значение                                                                            | Откуда                             |
|------------------------|-------------------------------------------------------------------------------------|------------------------------------|
| Текстовый экран        | 28 строк × 64 символа                                                               | текст № 4, № 9                     |
| Ячейка экранного ОЗУ   | биты 0–6 — код символа, бит 7 — «курсор» (инверсия)                                 | текст № 4, схема, код              |
| Адрес символа          | E800H + строка × 40H + столбец                                                      | код МОНИТОРА                       |
| Знакоместо             | 6 точек по горизонтали, 8 строк образа                                              | схема (выход Q5 регистра), дамп ЗГ |
| Знакогенератор         | `roms/chargen.bin`, адрес = код × 8 + строка; используется только 00H–7FH (A10 = 0) | схема, дамп № 6                    |
| Точки символа          | бит 5 — левая … бит 0 — правая; **0 — светится**                                    | дамп ЗГ, схема                     |
| Тактовая частота точек | 8 МГц (16 МГц с процессорного модуля / 2, DD1.1)                                    | схема (вывод)                      |
| Строчная развёртка     | период 63 мкс, синхроимпульс 4,5 мкс                                                | текст № 4                          |
| Начало вывода в строке | через 8 знакомест после конца строчного синхроимпульса                              | текст № 4                          |
| Кадровая развёртка     | период 20 160 мкс (≈ 49,6 Гц), синхроимпульс 1250 мкс                               | текст № 4                          |
| Счётчик строк символов | на 32 (5 разрядов адреса ОЗУ)                                                       | текст № 4                          |

Выведенные значения (не из текста, проверка арифметикой):

- знакоместо = 6 точек × 125 нс = 0,75 мкс; строка 63 мкс = 84 знакоместа; синхроимпульс
  4,5 мкс = 6 знакомест; видимая часть 64 × 0,75 = 48 мкс;
- кадр 20 160 мкс / 63 мкс = 320 строк растра = 32 строки символов × 10 строк растра
  (DD24 — К155ИЕ2, десятичный счётчик; видимых строк образа 8, по-видимому, две строки гасятся,
  в тексте сказано «восемь строк»); видимые 28 × 10 = 280 строк; кадровый синхроимпульс
  1250 мкс ≈ 20 строк растра;
- 32 строки × 64 = 2048 байт — ровно объём экранного ОЗУ; на экране — строки 0–27
  (смещения 000H–6FFH), строки 28–31 (700H–7FFH, адреса EF00H–EFFFH) не видны.

**Курсор.** Аппаратного курсора нет: символ инвертируется (светлый фон, тёмный символ), если
бит 7 установлен. МОНИТОР-«F» ставит бит 7 в ячейку, **следующую** за позицией курсора
(F7B2H + 1). Вероятная причина — бит D7 подаётся на «исключающее ИЛИ» DD9.1 без задержки и
инвертирует символ, который в этот момент выдвигается из регистра DD11, то есть предыдущий по
адресу. Для эмулятора: инвертировать знакоместо N, если бит 7 установлен у ячейки N + 1 (тогда
курсор окажется там, где его ждёт МОНИТОР). Если показывать инверсию «на месте», курсор будет
нарисован на одну позицию правее.

## Клавиатура

Матрица 8 столбцов (канал А, порт 07H) × 7 строк (канал В, порт 06H, биты 0–6), плюс три
клавиши-модификатора на канале С (порт 05H): бит 0 — РУС, бит 1 — УС, бит 2 — СС. Все сигналы
активны нулём. Расположение клавиш — [22-klaviatura-i-direktivy.md](22-klaviatura-i-direktivy.md).

Для эмуляции чтения порта 06H: результат = AND по всем нажатым клавишам, у которых столбец
выбран нулём в последнем значении, выведенном в порт 07H; бит 7 = 0. МОНИТОР выводит в 07H по
очереди FEH, FDH, … 7FH (опрос), а для быстрой проверки «нажата ли клавиша» — 00H.

| Номер N = 7 × столбец + строка | Код (без модификаторов)                                          |
|--------------------------------|------------------------------------------------------------------|
| 0–11                           | 30H–3BH: 0–9 : ;                                                 |
| 12–15                          | 2CH–2FH: , - . /                                                 |
| 16–47                          | 40H–5FH: @ A–Z [ \ ] ^ _                                         |
| 48–55                          | 20H (пробел), 18H →, 08H ←, 19H ↑, 1AH ↓, 0DH ВК, 1FH СТР, 0CH ↖ |

Модификаторы (для N < 48): УС — AND 1FH; СС — 30H–3BH → 20H–2BH, 2CH–2FH → 3CH–3FH; РУС —
OR 20H (латиница 40H–5FH → русские 60H–7FH). Клавиши РУС, УС, СС на схеме — переключатели с
RS-триггерами (подавление дребезга), их состояние читается как уровень, пока клавиша нажата
(есть ли у РУС фиксация — из журнала не ясно).

## Магнитофон, звук, часы

- Магнитофон и звук — бит 0 порта A1H процессорного модуля. Формат записи — как у «РК-86»
  (фазовое кодирование, синхробайт E6H, блок: адрес начала, адрес конца, данные, 00 00 E6,
  контрольная сумма), контрольная сумма — 16-разрядная сумма байтов (как у «Микро-80»).
  Константы: запись F7D0H = 1DH, чтение F7CFH = 2AH (после холодного старта).
- Часы МОНИТОРА-«F» — по прерыванию `RST 7` раз в секунду (датчик в процессорном модуле),
  обработчик FFC1H, время в F6FDH–F6FFH (BCD), вывод на индикаторы 9000H–9002H.
- Тактовая частота процессора — от КР580ГФ24 с кварцем 16 МГц (16 МГц / 9 ≈ 1,78 МГц —
  справочное свойство ГФ24, в этих статьях не указано). На дисплейный модуль передаётся сама
  частота 16 МГц.
