# 34. Программа POWER для CP/M

*Источник: «ЮТ для умелых рук» 1990-04, с. 13–14, рубрика «Твой персональный компьютер»,
статья «Запиши на кассету программу POWER». Автор — В. Бартенев, инженер.*

POWER — утилита для «ЮТ-88», работающего в операционной системе CP/M (см.
[31-cpm.md](31-cpm.md)). Она позволяет:

- просматривать файлы — в квазидиске или в ОЗУ;
- менять их содержимое, переименовывать, удалять;
- просматривать и заменять информацию в самом ОЗУ;
- узнавать состояние квазидиска, тестировать его и изолировать бракованные области памяти.

**Распечатка кодов в журнале не приводится** (объём программы около 15 Кбайт); редакция
предлагала высылать её по почте. Поэтому в `roms/` образа POWER нет.

## Вызов программы

После выхода в CP/M с помощью загрузчика CH.COM (см. [33-cpm-komandy.md](33-cpm-komandy.md))
загрузить файл `POWER.COM` в квазидиск, а затем ввести:

```
A> POWER (ВК)
```

После загрузки на экране появится приглашение:

```
A0=
```

### Формат команд

| Формат  | Вид                        |
|---------|----------------------------|
| простой | `A0=команда (ВК)`          |
| сложный | `A0=команда параметр (ВК)` |

Каждая команда может сопровождаться параметрами, изменяющими состояние работы. Отдельные
параметры могут задаваться вообще без команды.

В POWER можно использовать многозначные файловые ссылки, например:

```
A0=команда R*.*      или      A0=команда R**
```

— будет выведен каталог файлов, начинающихся с буквы R. Если в имени файла нужно указать
неизвестные буквы, ставится `?`:

```
A0=команда A??W.C?M
```

— каталог файлов, имена которых начинаются с буквы A, заканчиваются на W и содержат
максимум 4 буквы, а расширение содержит 3 буквы, начинается с C и заканчивается на M.

## Справка

| Команда | Назначение                     |
|---------|--------------------------------|
| `A0=?`  | весь перечень команд программы |
| `A0=??` | список скрытых команд          |

## Работа с диском и каталогом

| Команда                | Назначение                                                                                                                                               |
|------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------|
| `TEST`                 | тестирование диска: диск полностью прочитывается, вычисляется контрольная сумма, дефектные сектора изолируются в файл `====.===` для дальнейшего решения |
| `DISK`                 | ёмкость диска, формат, плотность записи и расположение системных треков                                                                                  |
| `STAT`                 | занятое и свободное пространство диска, состояние файлов (R/W — запись разрешена, R/O — запись запрещена)                                                |
| `DIR`                  | просмотр каталога                                                                                                                                        |
| `SORT n`               | сортировка каталога (см. ниже)                                                                                                                           |
| `REN *** (старое имя)` | переименование файла                                                                                                                                     |
| `SETSYS *** (имя)`     | сделать файл «невидимым» (системным); при этом он остаётся доступен из CP/M                                                                              |
| `SETDIR`               | обратная к `SETSYS`                                                                                                                                      |
| `SETRO *** (имя)`      | защита файла от записи                                                                                                                                   |
| `SETWR`                | обратная к `SETRO`                                                                                                                                       |
| `SIZE`                 | подробная информация о файле                                                                                                                             |
| `CHECK (имя файла)`    | подсчёт контрольной суммы файла                                                                                                                          |

Способы сортировки каталога:

| Команда  | Сортировка                                   |
|----------|----------------------------------------------|
| `SORT 1` | по именам файлов                             |
| `SORT 2` | по именам файлов, системные файлы в конце    |
| `SORT 3` | по типам (расширениям) файлов                |
| `SORT 4` | по типам расширения, системные файлы в конце |
| `SORT 0` | без сортировки                               |

Команда `SIZE` выводит четыре столбца: количество использованных секторов; количество
свободных секторов; объём памяти, занимаемый файлом (Кбайт); объём памяти, занимаемый группой
файлов.

## Пересылки между квазидиском и ОЗУ

1. `A0=LOAD (имя файла.тип) XXXX` — загружает файл из квазидиска в ОЗУ начиная с адреса
   XXXXH, **большего 4000H**. По завершении выводит конечный адрес в ОЗУ и число секторов,
   которые занимает файл.
2. `A0=SAVE (имя файла.тип) XXXX YY` — записывает в квазидиск файл из ОЗУ с адреса XXXXH,
   занимая YY секторов (если файл был загружен командой LOAD и его длина не увеличилась,
   число секторов можно не указывать).

## Работа с памятью

| Команда                               | Назначение                                                     |
|---------------------------------------|----------------------------------------------------------------|
| `DUMPA`                               | вывод на экран ASCII-символов                                  |
| `DUMPH`                               | вывод на экран шестнадцатеричных («двоичных») кодов            |
| `DUMPX`                               | вывод кодов и ASCII-символов                                   |
| `DUMPH XXXX YYYY`                     | вывод с адреса XXXXH по адрес YYYYH                            |
| `DUMPH XXXX,N`                        | вывод N байт с адреса XXXXH                                    |
| `DUMPH XXXX,,`                        | вывод всей памяти начиная с адреса XXXXH                       |
| `DS XXXX`                             | просмотр и исправление памяти начиная с XXXXH (см. ниже)       |
| `FILL XXXX YYYY ZZ`                   | заполнение XXXXH…YYYYH константой ZZH                          |
| `MOVE XXXX YYYY ZZZZ`                 | перемещение XXXXH…YYYYH по новому адресу ZZZZH                 |
| `CM XXXX YYYY ZZZZ`                   | сравнение области XXXXH…YYYYH с областью, начинающейся с ZZZZH |
| `SEARCH (нач.) (кон.) (байт) (байт)…` | поиск в памяти                                                 |

*Прим.: в журнале «DUMPH — вывод на экран двоичных кодов», «DUMPX — двоичных и ASCII
кодов»; по смыслу речь о шестнадцатеричном дампе.*

**DS.** На экран выводится строка вида

```
адрес ячейки  шестнадцатеричный  десятичный  двоичный  ASCII  ENTER
память        код                код         код       код    (.)
```

ENTER указывает, в каком коде будет вноситься изменение: (A), (H), (B), (D). Для перехода в
другой код надо ввести `.B (.)`, а в скобках указать один из символов. Просматривать
информацию можно в прямом и обратном направлении; для смены направления вводят `^`, при этом
у адреса появляется «-». Выход из DS — ввод двух точек.

**SEARCH** выводит номера найденных ячеек и коды (или символы ASCII), находящиеся в этих
ячейках. Максимальная длина строки — 128 символов. Если искомым символам предшествуют знаки
вопроса «?», найденные коды выводятся в контексте. Обычно ищутся шестнадцатеричные коды;
если искомая последовательность заключена в кавычки — ищутся символы ASCII.

## Запуск программ

| Команда                       | Назначение                                                                                                                                |
|-------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------|
| `GO (имя файла) XXXX`         | считывает программу с квазидиска, загружает в память с адреса XXXXH и передаёт ей управление (удобно для программ, работающих не со 100H) |
| `JP XXXX`                     | запуск программы, уже находящейся в памяти; по завершении — выход из POWER                                                                |
| `EX XXXX`                     | то же, но по завершении управление возвращается в POWER (программа должна кончаться командой `C9`, RET)                                   |
| `RUN (имя файла) (имя файла)` | загрузка и исполнение одного или нескольких файлов                                                                                        |
| `RUN`                         | то же для всего диска                                                                                                                     |
| `EXIT`                        | выход в CP/M                                                                                                                              |

## Настройка для «ЮТ-88»

При работе на «ЮТ-88» программа POWER требует настройки: **в ячейку 118H занести FFH**
(длина строки экрана — 64 символа).
