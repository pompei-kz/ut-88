# 33. Работа в CP/M: команды, CH.COM, STAT, CP/M-35

*Источник: «ЮТ для умелых рук» 1990-02, с. 12–15.*

## Загрузка и приглашение

Загрузка операционной системы CP/M осуществляется командой Монитора **G3100** (см.
[31-cpm.md](31-cpm.md)). После этого на экране появляется сообщение:

```
CPM V-2,2 ДИСК РАМ 256 K
A)
```

*Прим.: так в журнале; в коде загрузчика сообщение хранится латиницей/КОИ-7, на экране
«ЮТ-88» латинские строчные отображаются русскими буквами — отсюда «ДИСК РАМ». Приглашение CP/M
обычно выглядит как `A>`; в журнале везде печатается `A)`.*

Появление на экране подсказки `A)` говорит о готовности CP/M к работе и приёму команды. Если
ввести произвольный набор символов, например `A)BB`, и нажать «ВК», в ответ получим:

```
BB?
A)
```

При подаче несуществующей или синтаксически ошибочной команды система выполнить её не может:
она повторит введённую серию символов с добавлением знака вопроса и перейдёт в режим ожидания
новой команды, выдавая подсказку `A)`.

Если при наборе команды замечена ошибка ещё до нажатия ВК, можно вернуться назад клавишей
ПРОБЕЛ или одновременным нажатием УС+H.

Полезные управляющие символы:

| Клавиши | Действие                                                                 |
|---------|--------------------------------------------------------------------------|
| УС+X    | удаляет последнюю строку символов                                        |
| УС+M    | эквивалент нажатия ВК                                                    |
| УС+J    | эквивалент перевода строки                                               |
| УС+S    | приостанавливает вывод текста на дисплей; повторное нажатие возобновляет |
| УС+H    | возврат на символ назад                                                  |
| УС+C    | «горячий старт» (WBOOT)                                                  |

*Прим.: в журнале «ПРОБЕЛ» — вероятно, имеется в виду клавиша забоя («←»); оставлено как
напечатано.*

## Встроенные и транзитные команды

Команды CP/M делятся на две категории:

1. **встроенные** («резидентные»);
2. **транзитные**.

Встроенные команды являются частью ОС; обращение к ним — простым вводом имени команды,
независимо от того, есть ли в данный момент в системе квазидиск:

| Команда | Назначение                                   |
|---------|----------------------------------------------|
| `DIR`   | просмотр оглавления диска                    |
| `REN`   | переименование файлов                        |
| `ERA`   | удаление файлов                              |
| `TYPE`  | просмотр содержимого (текстового) файла      |
| `SAVE`  | сохранение на диске области ОЗУ в виде файла |

Например, команда `A)DIR (ВК)` на пустом квазидиске выдаст:

```
No files
A)
```

**Транзитные команды** хранятся на диске в отдельных файлах с расширением `.COM`. По сути это
программы CP/M; термин «транзитные» подчёркивает, что их можно загружать в ОЗУ **с адреса
100H**, заносить на диск, а при необходимости удалять. В нашем случае (квазидиск) все
транзитные команды хранятся на кассетах. Для вызова транзитной команды достаточно ввести имя
файла без расширения: CP/M найдёт в каталоге файл с этим именем и расширением `.COM` и запустит
его.

## Загрузчик файлов с магнитофона CH.COM

Таблица распечатки CH.COM приведена с меткой **CH.COM** (с. 11–12; в репозитории —
[`../roms/cpm-ch-com.hex`](../roms/cpm-ch-com.hex) и
[`../roms/cpm-ch-com.bin`](../roms/cpm-ch-com.bin), загружать с 0100H). Файл занимает
**100H–3FFH**. Контрольных сумм для CH.COM журнал не даёт; распечатка сверена с изображением
построчно, тексты сообщений в коде читаются осмысленно («CHANGER VERS 1.1», «READY TR FOR
INPUT, PRESS CR.», «DISK FULL.» и т. д.).

Порядок занесения CH.COM на диск:

1. В Мониторе «ЮТ-88» набрать программу с адреса 100H и записать на кассету.
2. Загруженную ранее CP/M перезапустить директивой «G» с адреса **DA00H** — появится подсказка
   `A)`.
3. Сохранить область 100H–3FFH (3 страницы по 256 байт) резидентной командой SAVE:

   ```
   A)SAVE 3 CH.COM (ВК)
   ```

4. Проверить: `A)DIR (ВК)` → `A: CH COM`.

### Работа CH.COM

Создадим вспомогательный файл и запишем его на ленту:

```
A)SAVE 1 EX.COM (ВК)
A)DIR
A: CH COM : EX COM
A)CH EX.COM (ВК)
```

Появится сообщение `CHANGER VERS1.1 READY TR FOR OUTPUT, PRESS CR`: если магнитофон готов к
записи и лентопротяжный механизм включён, нужно нажать ВК. После записи появляется сообщение
`READY TR FOR VERIFY, PRESS CR` — для проверки записи снова нажать ВК. При ошибке выводится
`VERIFY ERROR`; если всё в порядке — сообщений нет и снова появляется подсказка `A)`.

Удалим файл с диска и восстановим его с ленты:

```
A) ERA EX.COM (ВК)
A) DIR (ВК)
A: CH COM
A) CH EX.COM (ВК)
```

**Отсутствие имени файла в каталоге диска** приводит CH.COM в режим **чтения файла с ленты**:
на дисплее появится `READY TR FOR INPUT, PRESS CR`. При готовности магнитофона нужно нажать ВК.
Если файл считан правильно, появляется подсказка `A)`; проверить можно командой DIR.

Возможные сообщения при чтении:

| Сообщение                       | Значение                                               |
|---------------------------------|--------------------------------------------------------|
| `NO SOURCE PRESENT, READ ERROR` | файл не указан в командной строке или чтение с ошибкой |
| `NO DIRECTORY SPACE`            | не хватает места в каталоге диска                      |
| `NOT ENOUGH MEMORY`             | недостаточно места в ОЗУ электронного диска            |

## STAT.COM

STAT.COM применяется для получения списка имён файлов на диске, определения размеров файлов,
объёма неиспользованного дискового пространства и для других функций. Пусть с помощью CH.COM
STAT.COM считан на диск:

```
A)STAT (ВК)
A:R/W, SPACE : 152K
A)
```

— квазидиск в режиме ЧТЕНИЕ/ЗАПИСЬ, свободно 152 Кбайт. STAT позволяет изменить статус
диска, защитив его от записи:

```
A)STAT A:R/O
A)STAT (ВК)
A:R/O, SPACE:152K
```

Характеристики файлов:

```
A)STAT *.*(ВК)
RECS BYTES EXT ACC
  41   6K   1 R/O A:STAT.COM
BYTES REMAINING ON A:152K
```

| Поле    | Смысл                                                                           |
|---------|---------------------------------------------------------------------------------|
| `RECS`  | количество записей файла (одна запись — 128 байт)                               |
| `BYTES` | округлённый размер файла в килобайтах                                           |
| `EXT`   | экстент — ещё одна единица размера; если файл не превышает 16 Кбайт, выдаётся 1 |
| `ACC`   | статус доступа (ACCESS); R/O — только чтение                                    |

Имена в STAT (и в DIR, ERA) можно задавать с метасимволами: `*` — группа символов, `?` — один
символ:

| Пример          | Что выводится                                                                        |
|-----------------|--------------------------------------------------------------------------------------|
| `STAT FILE.*`   | все файлы с именем FILE и любым расширением                                          |
| `STAT *.COM`    | только командные файлы                                                               |
| `STAT FI??.?O?` | файлы, имена которых начинаются с FI плюс две любые буквы, расширение с O в середине |
| `STAT F??.*`    | файлы, начинающиеся с F, с любым расширением                                         |

В остальных случаях (кроме DIR и ERA) применение метасимволов приводит к ошибкам. В имени файла
может быть указано не более восьми символов, в расширении — не более трёх.

## REN, TYPE, ERA

```
A)REN FILE.COM=STAT.COM (ВК)
```

— переименование. Файл со статусом «только чтение» переименовать нельзя.

`TYPE` выводит на дисплей текстовые файлы.

`ERA` удаляет файлы:

```
A)ERA FILE.COM (ВК)
A)DIR (ВК)
NO files
A)ERA *.* (ВК)
```

Файлы со статусом «ТОЛЬКО ЧТЕНИЕ» удалены быть не могут. Во избежание неожиданностей прежде
чем удалять с метасимволами, выполните DIR с той же маской и проверьте список.

## CP/M-35 — версия без дополнительного блока ОЗУ

В заключение в журнале приведена ещё одна версия CP/M, для которой **не требуется
дополнительного блока ОЗУ**. Её электронный квазидиск создаётся в адресном пространстве
самого компьютера за счёт сокращения рабочей области ОЗУ. Ограниченный объём рабочей области и
квазидиска не даёт использовать все преимущества файловой организации, но позволяет освоить
работу с резидентными командами и CH.COM, загружая небольшие файлы с кассетного магнитофона.

Таблица распечатки обозначена метками **CP/M 35** (с. 14–16 и правая колонка с. 3, адреса 3400H–4C5FH; блок 3C00H–3FFFH из-за вёрстки
оказался на с. 3, см. [35-dampy.md](35-dampy.md));
**пусковой адрес 4A00H**. В репозитории — [`../roms/cpm35.hex`](../roms/cpm35.hex) и
[`../roms/cpm35.bin`](../roms/cpm35.bin) (6240 байт, загружать с 3400H).

### Контрольные суммы CP/M-35

| Директива   | Сумма | Сверка с распечаткой                 |
|-------------|-------|--------------------------------------|
| K3400, 37FF | 7AB9  | совпала                              |
| K3800, 3BFF | A41E  | совпала                              |
| K3C00, 3FFF | AA1F  | совпала                              |
| K4000, 43FF | D0B8  | совпала                              |
| K4400, 47FF | ADA0  | совпала                              |
| K4800, 4BFF | 7D22  | не сошлась: в распечатке на 6 больше |
| K4C00, 4C55 | 1DA1  | совпала                              |
| K3100, 4C55 | E211  | не сошлась (из-за блока 4800H)       |

*Прим.: последняя строка в журнале — «K3100, 4C55», хотя распечатка CP/M-35 начинается с
3400H; сумма E211H равна сумме остальных строк журнала, то есть область 3100H–33FFH в ней не
участвует (или содержит нули). Таблица сверена со сканом (с. 15).*

*Прим. (не из журнала): CP/M-35 — та же CP/M 2.2 (CCP с 3400H, БДОС с 3C06H), но собранная
для работы с 3400H; её CCP и БДОС совпадают с CP/M-64 байт в байт с точностью до старших
байтов адресов (разница 90H). Это использовано для перекрёстной проверки обеих распечаток (см.
[35-dampy.md](35-dampy.md)). БСВВ CP/M-35 (4A00H–4C55H) — другая: заставка «35K CP/M VERS
2.2», в ней есть ссылки на адреса 74xxH и 4D72H, лежащие вне распечатки, — так в журнале.*
