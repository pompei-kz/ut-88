asm-k580vm80a — ассемблер процессора КР580ВМ80А (Intel 8080) для компьютера ЮТ-88

ИСПОЛЬЗОВАНИЕ

  asm-k580vm80a -f ВХОД.asm -o ВЫХОД [-t bin|hex|ihex|link] [-l ЛИСТИНГ.lst]
                [-D ИМЯ[=ЗНАЧЕНИЕ]]... [-I ПАПКА]... [--fill XX] [--charset koi7|ascii]
                [--base АДРЕС]
  asm-k580vm80a -h      эта справка (по-русски)
  asm-k580vm80a -he     та же справка по-английски
  asm-k580vm80a -V      версия

КЛЮЧИ

  -f ФАЙЛ        исходный текст (обязателен), UTF-8.
                   asm-k580vm80a -f hello.asm -o hello.hex
  -o ФАЙЛ        выходной файл (обязателен). При ошибках сборки не создаётся.
  -t ТИП         тип выходного файла: bin, hex, ihex, link. Если задан, расширение
                 имени из -o не важно.
                   asm-k580vm80a -f hello.asm -o hello.txt -t hex
                   asm-k580vm80a -f rom.asm -o rom.img -t bin
  -l ФАЙЛ        листинг: адрес, коды, исходная строка, таблица символов (см. ЛИСТИНГ).
                   asm-k580vm80a -f prog.asm -o prog.hex -l prog.lst
  -D ИМЯ[=ЗН]    определить символ, как EQU в начале текста. Без значения — 1.
                 Значение — число в записи ассемблера (0C000H, 10, -1, $FF).
                   asm-k580vm80a -f prog.asm -o prog.bin -D DEBUG -D BASE=0C000H
  -I ПАПКА       папка поиска файлов INCLUDE и INCBIN, можно несколько раз. Сначала
                 ищется в папке файла с директивой, затем в папках -I по порядку.
                   asm-k580vm80a -f game.asm -o game.hex -I data -I ../common
  --fill XX      байт-заполнитель пропусков в bin (шестнадцатеричный, по умолчанию 00).
                   asm-k580vm80a -f rom.asm -o rom.bin --fill FF
  --charset К    кодировка строк и символьных констант: koi7 (по умолчанию) или ascii.
  --base АДРЕС   адрес начала сегмента CSEG при сборке сразу в bin/hex/ihex
                 (шестнадцатеричный, по умолчанию 0000); DSEG — сразу за CSEG.
                   asm-k580vm80a -f prog.asm -o prog.hex --base C000
  -h, -he, -V    справка по-русски, по-английски, версия.

  Запуск без аргументов печатает краткую подсказку.
  Код выхода: 0 — успех, 1 — ошибки сборки, 2 — ошибка в командной строке.

ВЫБОР ФОРМАТА ВЫХОДА

  Если -t не задан, тип берётся по расширению имени из -o:

    .bin, .rom     bin  — сплошной образ памяти
    .hex           hex  — дамп как в журнале «ЮТ для умелых рук»
    .ihx, .ihex    ihex — Intel HEX
    .link          link — объектный файл для компоновщика (в разработке)

  Другое расширение без -t — ошибка. -t всегда важнее расширения:
    -o prog.bin -t hex   даёт текстовый дамп в файле prog.bin.

ФОРМАТЫ ВЫХОДНЫХ ФАЙЛОВ

  bin   байты от наименьшего до наибольшего занятого адреса; пропуски (ORG вперёд,
        DS без заполнителя) заполняются байтом --fill (00). Адрес загрузки в файле не
        хранится — его нужно знать (обычно это первый ORG).
  hex   текстовый дамп, как в журнале и в monitor/monitor.hex — его читает эмулятор:
          C000 31 EE C3 3E 11 C3 3B 00 C3 00 01 F7 EB C3 7D 00
          C010 D5 AF
        Адрес (4 шестнадцатеричные цифры) и до 16 байт; строки начинаются на границе
        16 байт, пропуски в памяти не заполняются (новая строка с новым адресом).
  ihex  Intel HEX: записи 00 (данные, до 16 байт, по границам 16), запись 03 с
        адресом пуска из END (если указан), запись 01 (конец файла).
          :09C000003E112100C0EFC306C08F
          :040000030000C00039      (адрес пуска C000H)
          :00000001FF

ЛИСТИНГ (-l)

  Листинг пишется вместе с выходным файлом любого типа (при ошибках не создаётся),
  формат — как у monitor/monitor.lst:

    0000  31 EE C3      START:      LXI     SP,STACK
    03FA  FF FF FF FF               DB      0FFH,0FFH,0FFH,0FFH,0FFH,0FFH
    03FE  FF FF
         =9000          DISP_D      EQU     9000H
    C016  00           +        NOP
                       -        MVI     B,2
    0003' 01 02 03 04 1         DB 1,2,3,4

  * столбцы 1–4 — адрес (у строки без кодов — только если на ней метка или DS);
    5-й — пробел для абсолютного адреса, ' — смещение в CSEG, " — в DSEG;
  * до 4 байт кода; длинные DB, DW, DS, INCBIN продолжаются на следующих строках
    (адрес и коды, без текста);
  * у EQU и SET вместо адреса — =значение (* — значение от внешнего символа);
  * 19-й столбец — глубина INCLUDE (пусто — основной файл, 1, 2…), 20-й — «+» у
    строк раскрытия макроса или REPT, «-» у строк ложной ветки IF (не собираются);
  * с 21-го столбца — исходная строка. Директивы препроцессора и тела определяемых
    макросов показываются без кодов.

  В конце — таблица символов по алфавиту: имя, значение, сегмент (абс., CSEG, DSEG,
  внешн.), вид (метка, EQU, SET, EXTRN, -D; PUBLIC) и где определён (файл:строка).
  Адреса CSEG/DSEG в листинге — смещения от начала сегмента.
    asm-k580vm80a -f prog.asm -o prog.hex -l prog.lst

СИНТАКСИС СТРОКИ

  [метка[:]]  [мнемоника|директива  [операнды]]  [; комментарий]

  * Метка — имя с двоеточием в любом месте строки или имя без двоеточия с первого
    столбца. Имя перед EQU, SET и MACRO — метка, даже если строка начинается с отступа.
  * Имя: латинские буквы, цифры, _ ? @ . ; первая — не цифра. Регистр букв в
    мнемониках, регистрах, директивах и ИМЕНАХ не важен: Loop, LOOP и loop — одно
    имя.
  * Зарезервированы и не могут быть именами: регистры A B C D E H L M SP PSW и
    слова-операторы MOD SHL SHR AND OR XOR NOT EQ NE LT LE GT GE HIGH LOW.
  * Операнды разделяются запятыми; комментарий — от «;» до конца строки (кроме «;»
    внутри кавычек).

    START:  LXI   SP,0C3EEH     ; вершина стека
    LOOP    DCR   B             ; метка без двоеточия с первого столбца
            JNZ   LOOP
    COUNT   EQU   10

ЧИСЛА

  0C000H, 0FFh     шестнадцатеричные с суффиксом H (впереди цифра: 0FFH, не FFH)
  0x1F, $1F        шестнадцатеричные с префиксом
  1010B            двоичные
  17O, 17Q         восьмеричные
  99, 99D          десятичные
  'A', 'AB'        символьные константы: код символа; два символа — слово
                   (первый — старший байт), 'Я' — код в кодировке --charset
  $                адрес начала текущей строки (команды или директивы)

ВЫРАЖЕНИЯ

  Операции по убыванию приоритета:

    ( )                          скобки
    + - HIGH LOW                 унарные: плюс, минус, старший/младший байт
    * / MOD SHL SHR              умножение, деление, остаток, сдвиги
    + -                          сложение, вычитание
    EQ NE LT LE GT GE            сравнения, также = <> < <= > >=
                                 (истина — 0FFFFH, ложь — 0)
    NOT                          поразрядное НЕ
    AND                          поразрядное И
    OR XOR                       поразрядные ИЛИ, исключающее ИЛИ

  Арифметика целочисленная. Байт-операнд допускает -256…255 (отрицательные берутся
  по модулю 256: -1 = 0FFH, NOT 80H = 7FH), слово — -65535…65535.

    MVI   A,HIGH (TABLE+10)
    LXI   H,BUF+2*SIZE
    CPI   'Z'+1
    ANI   NOT 80H
    DB    (END_ADDR-START) MOD 256

ПЕРЕМЕЩАЕМЫЕ ЗНАЧЕНИЯ

  Адрес метки в сегменте CSEG или DSEG и внешний символ (EXTRN) — перемещаемые:
  их окончательное значение известно только после размещения. С ними можно:
    метка ± константа, константа + метка        (перемещаемое)
    метка1 - метка2 из одного сегмента            (абсолютное — расстояние)
    HIGH метка, LOW метка                         (байт перемещаемого адреса)
    сравнение двух меток одного сегмента
  Всё остальное (умножение, NOT, сумма двух меток, -метка, HIGH метка + 1 …) —
  ошибка «выражение нельзя переместить». Метки в ASEG (и вне сегментов) абсолютны.

ДИРЕКТИВЫ

  ORG адрес              адрес размещения следующих байтов (в CSEG/DSEG — смещение от
                         начала сегмента). Значение должно быть известно (без ссылок
                         вперёд).
                           ORG 0C000H
  имя EQU выражение      постоянный символ; переопределять нельзя.
                           SCREEN  EQU 0E800H
  имя SET выражение      переопределяемый символ.
                           N SET 0
                           N SET N+1
  DB выр|'строка',...    байты; строки в '…' или "…" (кавычка внутри — удвоить:
  DEFB                   'It''s'). Русские буквы — в кодировке --charset.
                           MSG: DB 'ПРИВЕТ', 0DH, 0AH, 0
                                DB 'A'+80H, LOW ADDR, HIGH ADDR
  DW выр,...             слова (16 бит, младший байт первым).
  DEFW                     TABLE: DW START, LOOP, 0
  DS n[,заполнитель]     резерв n байт; с заполнителем — n одинаковых байтов. Без
  DEFS                   заполнителя место в bin заполняется --fill, в hex/ihex
                         пропускается.
                           BUF: DS 64
                                DS 16, 0FFH
  END [адрес]            конец текста (дальше ничего не читается); адрес — точка
                         пуска (запись 03 в Intel HEX).
                           END START
  INCBIN "файл"          вставить байты файла как есть (поиск — как у -I).
                           FONT: INCBIN "font.bin"
  CSEG                   сегмент кода (перемещаемый).
  DSEG                   сегмент данных (перемещаемый).
  ASEG                   абсолютный сегмент — адреса по ORG (действует по умолчанию).
                         У каждого сегмента свой счётчик адреса; переключаться можно
                         сколько угодно раз. При сборке в bin/hex/ihex CSEG ставится с
                         --base (0000), DSEG — сразу за ним.
                           CSEG
                           START: LXI H,BUF
                           DSEG
                           BUF:   DS 10
  NAME имя               имя модуля (для объектных файлов).
  PUBLIC имя,...         экспорт символов для других модулей (синоним GLOBAL).
  EXTRN имя,...          символы из других модулей (синоним EXTERN). При сборке
                         сразу в bin/hex/ihex ссылка на EXTRN — ошибка: такие
                         программы собираются в .link и компонуются.

ПРЕПРОЦЕССОР

  Директивы препроцессора выполняются при чтении текста, до сборки строки: вставляют
  файлы, выбирают ветки условной сборки, раскрывают макросы и повторы. Имена
  директив, как и команд, пишутся любыми буквами (IF, if, If).

  INCLUDE "файл"         вставить текст файла вместо этой строки. Поиск: папка файла,
                         в котором стоит INCLUDE, затем папки -I по порядку, затем
                         текущая папка. Включения могут быть вложенными (до 16
                         уровней); включение файла, который уже включается
                         (рекурсия), — ошибка. Ошибка во включённом файле
                         показывается с его именем и строкой и цепочкой примечаний
                         «включено из main.asm:3».
                           INCLUDE "defs.inc"

  IF выражение           условная сборка: строки до ELSE (или до ENDIF) собираются,
  ELSE                   если значение не 0, иначе — строки после ELSE. Выражение
  ENDIF                  вычисляется при чтении строки: символы в нём должны быть
                         определены выше по тексту или ключом -D (ссылка вперёд —
                         ошибка), значение — абсолютное. IF можно вкладывать; строки
                         ложной ветки не разбираются и не собираются. IF, открытый во
                         включённом файле или в макросе, закрывается там же.
  IFDEF имя              как IF, условие — символ определён выше по тексту или
  IFNDEF имя             ключом -D (у IFNDEF — не определён).
                           IFDEF   DEBUG
                           CALL    DUMP
                           ENDIF
                           IF      BAUD GT 1200
                           MVI     A,1
                           ELSE
                           MVI     A,2
                           ENDIF

  имя MACRO [п1,п2,...]  определить макрос; тело — до ENDM. Вызов — как команда:
  ENDM                   [метка:] имя [а1,а2,...]. Параметры заменяются текстом
                         аргументов по словам (регистр букв не важен), недостающие
                         аргументы — пустые, лишние — ошибка. Аргумент с запятой
                         берётся в <…> (скобки снимаются), в кавычки или в круглые
                         скобки. Внутри кавычек подставляется только запись &п; знак
                         & вне кавычек склеивает слова: L&N при N=1 даёт L1.
                         Комментарии не меняются. Макрос можно вызывать из макроса и
                         рекурсивно (с выходом по IF/EXITM), вложенность — до 64
                         уровней, глубже — ошибка «возможна бесконечная рекурсия».
                         Макрос можно переопределить; имя не может совпадать с
                         командой или директивой. Вызов макроса с первого столбца
                         — вызов, а не метка.
  LOCAL имя,...          (в теле макроса или REPT) локальные метки: при каждом
                         раскрытии имена заменяются уникальными ??0001, ??0002…
  EXITM                  досрочно закончить раскрытие макроса (в REPT — все
                         оставшиеся повторы).
                           DELAY   MACRO   N           ; задержка N циклов
                                   LOCAL   AGAIN
                                   MVI     B,N
                           AGAIN:  DCR     B
                                   JNZ     AGAIN
                                   ENDM
                           OUTP    MACRO   PORT,VAL
                                   IF      VAL = 0
                                   XRA     A
                                   ELSE
                                   MVI     A,VAL
                                   ENDIF
                                   OUT     PORT
                                   ENDM
                                   OUTP    0A1H,0
                                   DELAY   10
                                   DELAY   20          ; своя метка AGAIN

  REPT n                 повторить строки до ENDM n раз (0…65535; значение должно быть
  ENDM                   известно выше по тексту). REPT и MACRO можно вкладывать.
                           N       SET     0
                                   REPT    4
                           N       SET     N+1
                                   DB      N*N         ; 1, 4, 9, 16
                                   ENDM

  Ошибка в теле макроса показывает строку тела и место вызова:
    prog.asm:3:15: ошибка: неизвестный символ X
        примечание: из макроса DELAY, вызванного в prog.asm:12
  Незакрытые IF, MACRO и REPT — ошибки («IF без ENDIF», «MACRO без ENDM»).

КОДИРОВКА СТРОК

  koi7 (по умолчанию) — КОИ-7 ЮТ-88, как знакогенератор дисплейного модуля:
    20H–5FH как в ASCII (пробел, цифры, знаки, латинские прописные);
    60H–7EH русские буквы Ю А Б Ц Д Е Ф Г Х И Й К Л М Н О П Я Р С Т У Ж В Ь Ы З Ш Э Щ Ч
    (строчные русские — те же коды, Ё = Е; буквы Ъ нет — ошибка);
    строчные латинские остаются кодами ASCII 61H–7AH (на экране ЮТ-88 это русские).
  ascii — только ASCII, русские буквы — ошибка.

КОМАНДЫ КР580ВМ80А

  r — регистр B C D E H L M A (M — ячейка по адресу HL); rp — пара B (BC), D (DE),
  H (HL), SP; d8 — байт; d16/a16 — слово/адрес; port — номер порта 0–255.

  Пересылки:   MOV r,r   MVI r,d8   LXI rp,d16   LDA a16   STA a16   LHLD a16
               SHLD a16  LDAX B|D   STAX B|D     XCHG
  Арифметика:  ADD r  ADC r  SUB r  SBB r  ADI d8  ACI d8  SUI d8  SBI d8
               INR r  DCR r  INX rp  DCX rp  DAD rp  DAA
  Логика:      ANA r  XRA r  ORA r  CMP r  ANI d8  XRI d8  ORI d8  CPI d8
               RLC  RRC  RAL  RAR  CMA  CMC  STC
  Переходы:    JMP a16  JNZ JZ JNC JC JPO JPE JP JM a16
               CALL a16 CNZ CZ CNC CC CPO CPE CP CM a16
               RET  RNZ RZ RNC RC RPO RPE RP RM   RST 0…7   PCHL
  Стек:        PUSH B|D|H|PSW   POP B|D|H|PSW   XTHL   SPHL
  Ввод-вывод:  IN port   OUT port
  Управление:  EI  DI  HLT  NOP

  MOV M,M нет (это код HLT). Всего 244 кода; недокументированные коды не собираются.

СООБЩЕНИЯ ОБ ОШИБКАХ

  файл:строка:столбец: ошибка: текст
    hello.asm:12:9: ошибка: неизвестный символ PRNT
  Выходной файл при ошибках не создаётся.

ПРИМЕР ПРОГРАММЫ

  ; «11» на индикаторах модуля 1 (МОНИТОР в ПЗУ 0000H)
          ORG   0C000H
  START:  MVI   A,11H           ; что показать
          LXI   H,0C000H        ; адрес для разрядов адреса
          RST   5               ; вывод на индикатор
  STOP:   JMP   STOP
          END   START

    asm-k580vm80a -f eleven.asm -o eleven.hex
    asm-k580vm80a -f eleven.asm -o eleven.bin
    asm-k580vm80a -f eleven.asm -o eleven.ihx
