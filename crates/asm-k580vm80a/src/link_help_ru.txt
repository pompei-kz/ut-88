link-k580vm80a — компоновщик объектных файлов .link ассемблера КР580ВМ80А для ЮТ-88

ИСПОЛЬЗОВАНИЕ

  link-k580vm80a МОДУЛЬ.link... -o ВЫХОД [-t bin|hex|ihex] [-m КАРТА.map]
                 [--base АДРЕС] [--cseg АДРЕС] [--dseg АДРЕС] [-e СИМВОЛ] [--fill XX]
  link-k580vm80a -h      эта справка (по-русски)
  link-k580vm80a -he     та же справка по-английски
  link-k580vm80a -V      версия

  Компоновщик собирает программу из нескольких модулей, собранных ассемблером
  asm-k580vm80a в объектные файлы (-t link или расширение .link): раскладывает
  сегменты модулей по памяти, связывает символы PUBLIC и EXTRN, исправляет адреса
  (перемещения) и пишет готовый образ памяти в bin, hex или ihex — теми же
  форматами, что и ассемблер.

КЛЮЧИ

  МОДУЛЬ.link    объектные файлы (хотя бы один), в порядке раскладки.
                   link-k580vm80a main.link print.link -o hello.hex
  -o ФАЙЛ        выходной файл (обязателен). При ошибках не создаётся.
  -t ТИП         тип выходного файла: bin, hex, ihex. Без -t — по расширению -o:
                 .bin, .rom — bin; .hex — дамп как в журнале; .ihx, .ihex — Intel HEX.
                 Объединить модули в один .link нельзя.
                   link-k580vm80a main.link print.link -o hello.txt -t ihex
  -m ФАЙЛ        карта компоновки (см. КАРТА .map).
                   link-k580vm80a main.link print.link -o hello.hex -m hello.map
  --base АДРЕС   начало программы: адрес CSEG первого модуля (шестнадцатеричный).
                 По умолчанию C000 — начало ОЗУ пользователя ЮТ-88.
                   link-k580vm80a main.link print.link -o hello.bin --base 3000
  --cseg АДРЕС   то же, что --base (если заданы оба, --cseg важнее).
  --dseg АДРЕС   адрес DSEG первого модуля. По умолчанию данные идут сразу за
                 кодом всех модулей.
                   link-k580vm80a main.link print.link -o hello.hex --dseg D000
  -e СИМВОЛ      адрес пуска — значение символа PUBLIC (запись 03 в Intel HEX).
                 Без -e адрес пуска берётся из END адрес — он должен быть не более
                 чем в одном модуле.
                   link-k580vm80a main.link print.link -o hello.ihx -e START
  --fill XX      байт-заполнитель пропусков в bin (шестнадцатеричный, по умолчанию
                 00).
                   link-k580vm80a main.link print.link -o hello.bin --fill FF
  -h, -he, -V    справка по-русски, по-английски, версия.

  Числа в ключах — шестнадцатеричные: C000, 0C000H, 0xC000, $C000.
  Запуск без аргументов печатает краткую подсказку.
  Код выхода: 0 — успех, 1 — ошибки в модулях или при компоновке, 2 — ошибка в
  командной строке.

РАСКЛАДКА ПАМЯТИ

  * CSEG всех модулей кладутся подряд, в порядке файлов в командной строке, с
    адреса --cseg/--base (C000H).
  * DSEG всех модулей — подряд в том же порядке, с адреса --dseg или сразу после
    кода последнего модуля.
  * ASEG (абсолютные части, адреса по ORG) остаются на своих адресах.
  * Размер сегмента включает резерв DS; выравнивания нет.
  * Пересечение областей двух модулей (или с ASEG) — ошибка, выход за FFFFH — тоже.

  Модули main (CSEG 9 байт, DSEG 7 байт) и print (CSEG 11 байт) при --base 3000:
    main  CSEG 3000H–3008H,  print CSEG 3009H–3013H,  main DSEG 3014H–301AH.

  Так же раскладывает сегменты ассемблер при сборке одного файла сразу в
  bin/hex/ihex: программа из модулей, скомпонованная с --base X, байт в байт равна
  сборке того же текста одним файлом (CSEG частей подряд, затем DSEG частей) с
  asm-k580vm80a --base X.

СИМВОЛЫ И ПЕРЕМЕЩЕНИЯ

  * Символ из EXTRN должен быть объявлен PUBLIC ровно в одном модуле; регистр букв
    в именах не важен (как в ассемблере). PUBLIC может быть меткой CSEG/DSEG,
    абсолютным значением (EQU) или «внешний символ ± константа».
  * Перемещения бывают трёх видов: WORD (адрес целиком, 2 байта), LOW и HIGH
    (младший и старший байт адреса). Цель — начало CSEG/DSEG своего модуля или
    внешний символ, плюс константа:
      LXI   H,MSG+2           ; WORD DSEG +0002
      CALL  PRINT             ; WORD EXT PRINT +0000
      MVI   A,HIGH (BUF+10H)  ; HIGH EXT BUF +0010
  * У LOW и HIGH адрес цели вместе с константой должен лежать в 0000H–FFFFH, иначе
    байт неоднозначен — ошибка «переполнение». WORD берётся по модулю 10000H.

СООБЩЕНИЯ ОБ ОШИБКАХ

  Ошибки в объектном файле — с местом в нём (файл:строка:столбец):
    main.link:1:10: ошибка: неподдерживаемая версия формата .link «2» (поддерживается 1)
    main.link:14:1: ошибка: файл обрезан: нет завершающей строки END
  Ошибки компоновки называют модуль, файл и место в исходном тексте:
    ошибка: модуль MAIN (main.link): внешний символ PRINT не найден ни в одном
      модуле (нет PUBLIC PRINT); EXTRN в main.asm:2:17
        примечание: используется: CSEG смещение 0004H, main.asm:6:17
    ошибка: символ PRINT определён повторно: модуль PRINT (print.link),
      print.asm:2:17 и модуль PRINT2 (print2.link), print2.asm:3:17
    ошибка: перекрытие областей памяти: модуль A (a.link) ASEG (F000H–F00FH) и
      модуль B (b.link) CSEG (F008H–F01FH)
    main.asm:7:17: ошибка: модуль MAIN: переполнение: HIGH от адреса 10010H ...
  Также ошибки: несколько модулей с END адрес (без -e), -e с неизвестным символом,
  выход за пределы адресного пространства. Выходной файл и карта при ошибках не
  создаются.

КАРТА .map (-m)

  КАРТА КОМПОНОВКИ link-k580vm80a

  СЕГМЕНТЫ МОДУЛЕЙ

    Модуль  Файл        Сегмент  Начало  Конец  Размер
    MAIN    main.link   CSEG     3000H   3008H  0009H
    MAIN    main.link   DSEG     3014H   301AH  0007H
    PRINT   print.link  CSEG     3009H   3013H  000BH

  СИМВОЛЫ PUBLIC ПО ИМЕНИ

    Символ  Значение  Сегмент  Модуль
    PRINT   3009H     CSEG     PRINT
    START   3000H     CSEG     MAIN

  СИМВОЛЫ PUBLIC ПО АДРЕСУ

    Символ  Значение  Сегмент  Модуль
    START   3000H     CSEG     MAIN
    PRINT   3009H     CSEG     PRINT

  АДРЕС ПУСКА: 3000H (END в модуле MAIN)

  Сегменты — по модулям в порядке файлов (ASEG — каждый непрерывный кусок данных
  отдельной строкой); столбец «Сегмент» у символа: ASEG — абсолютное значение,
  EXT — внешний символ ± константа. Имя модуля — из NAME, без NAME — имя файла без
  расширения.

ОБЪЕКТНЫЙ ФАЙЛ .link

  Текстовый, построчный; его пишет asm-k580vm80a -t link. Первая строка —
  UT88LINK и версия формата, последняя — END; строки с «;» в начале — комментарии.
  Числа шестнадцатеричные, смещения — от начала сегмента.

    UT88LINK 1
    MODULE MAIN                                 имя модуля из NAME (если есть)
    SEGMENT CSEG 0009                           сегмент и размер (с резервом DS)
    DATA CSEG 0000 21 00 00 CD 00 00 C3 6C F8   байты с данного смещения
    SEGMENT DSEG 0007
    DATA DSEG 0000 70 72 69 77 65 74 00
    EXTERN PRINT AT main.asm:2:17               импорт
    PUBLIC START CSEG 0000 AT main.asm:3:17     экспорт: сегмент и смещение
    RELOC CSEG 0001 WORD DSEG +0000 AT main.asm:5:19
    RELOC CSEG 0004 WORD EXT PRINT +0000 AT main.asm:6:17
    ENTRY CSEG 0000                             адрес пуска из END
    END

  RELOC: где (сегмент, смещение), вид (WORD, LOW, HIGH), цель (CSEG, DSEG или
  EXT имя), константа со знаком. PUBLIC с сегментом ASEG — абсолютное значение,
  PUBLIC имя EXT другое ±n — значение от внешнего символа. AT файл:строка:столбец
  — место в исходном тексте для сообщений. В данных на месте перемещения лежит
  значение при базе 0.

ПРИМЕР

  main.asm:
          NAME    MAIN
          EXTRN   PRINT
          PUBLIC  START
          CSEG
  START:  LXI     H,MSG
          CALL    PRINT
          JMP     0F86CH          ; выход в МОНИТОР
          DSEG
  MSG:    DB      'ПРИВЕТ',0
          END     START

  print.asm:
          NAME    PRINT
          PUBLIC  PRINT
          CSEG
  PRINT:  MOV     A,M             ; HL — адрес строки, 0 — конец
          ORA     A
          RZ
          MOV     C,A
          CALL    0F809H          ; вывод символа из C
          INX     H
          JMP     PRINT

    asm-k580vm80a -f main.asm -o main.link
    asm-k580vm80a -f print.asm -o print.link
    link-k580vm80a main.link print.link -o hello.hex -m hello.map --base 3000

  hello.hex:
    3000 21 14 30 CD 09 30 C3 6C F8 7E B7 C8 4F CD 09 F8
    3010 23 C3 09 30 70 72 69 77 65 74 00
