# Тестовые программы процессора 8080

Известные тестовые программы для Intel 8080, работающие под CP/M (формат `.COM`, загрузка
и запуск с адреса 0100H). Используются интеграционными тестами `tests/cpm_programs.rs`:
программа запускается с 0100H, вызовы BDOS (`CALL 0005H`, функции 2 и 9) выводят текст в
строку, переход на 0000H завершает программу.
